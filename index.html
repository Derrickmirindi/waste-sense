⚙️ Backend Configuration

The best.pt PyTorch model cannot run directly in the browser. Connect to a backend inference API (e.g., FastAPI/Flask serving Ultralytics YOLO).

Interactive API docs (Swagger UI): http://localhost:8000/docs

Demo mode generates simulated detections so you can preview the interface without a backend. For production, deploy best.pt using a FastAPI server with Ultralytics.

🐍 Sample Backend (FastAPI)

from fastapi import FastAPI, UploadFile
from fastapi.middleware.cors import CORSMiddleware
from ultralytics import YOLO
from PIL import Image
import io

app = FastAPI()
app.add_middleware(CORSMiddleware, allow_origins=["*"], allow_methods=["*"], allow_headers=["*"])
model = YOLO("best.pt")

@app.post("/predict")
async def predict(file: UploadFile, conf: float = 0.4, iou: float = 0.45):
    img = Image.open(io.BytesIO(await file.read())).convert("RGB")
    res = model.predict(img, conf=conf, iou=iou, imgsz=640, verbose=False)[0]
    dets = []
    for b in res.boxes:
        x1,y1,x2,y2 = b.xyxy[0].tolist()
        dets.append({
          "bbox":[x1,y1,x2,y2],
          "class_id": int(b.cls[0]),
          "class_name": model.names[int(b.cls[0])],
          "confidence": float(b.conf[0])
        })
    return {"detections": dets, "image_size": list(img.size)}
